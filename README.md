# Aplicação Prática: Bubble Sort e Quick Sort

## 1. Objetivo

Este projeto foi desenvolvido para a atividade avaliativa da disciplina Algoritmos e Pensamento Computacional, do Centro Universitário UDF. A aplicação utiliza a linguagem C para ordenar temperaturas por meio dos algoritmos Bubble Sort e Quick Sort.

## 2. Situação-problema

A organização de temperaturas pode ajudar a analisar registros climáticos, identificar os menores e maiores valores e facilitar a comparação entre diferentes medições.

A aplicação recebe dez temperaturas informadas pelo usuário e organiza os valores em ordem crescente, permitindo observar o funcionamento de dois algoritmos de ordenação.

## 3. Funcionamento do programa

O programa solicita dez temperaturas e apresenta os valores originais. Em seguida, utiliza cópias dos mesmos dados para executar os dois algoritmos separadamente.

Ao final, exibe os resultados do Bubble Sort e do Quick Sort, ambos em ordem crescente.

## 4. Algoritmos utilizados

### Bubble Sort

O Bubble Sort compara elementos vizinhos e troca suas posições quando estão na ordem incorreta. Esse processo se repete até que os valores estejam ordenados.

### Quick Sort

O Quick Sort escolhe um elemento chamado pivô e divide os dados em partes menores e maiores em relação a ele. Depois, aplica o mesmo processo recursivamente às partes até concluir a ordenação.

## 5. Tecnologias utilizadas

- Linguagem C.
- OnlineGDB para desenvolvimento e testes.
- GitHub para armazenamento e versionamento do projeto.

## 6. Como executar

1. Baixe o arquivo `ordenacao_temperaturas.c`.
2. Abra o arquivo em um compilador C, como o OnlineGDB.
3. Selecione a linguagem C.
4. Execute o programa.
5. Informe as dez temperaturas solicitadas.
6. Confira os dados originais e os resultados dos dois algoritmos.
7. Ou utilize o link: https://onlinegdb.com/wu3_mn39T
## 7. Exemplo de execução

**Temperaturas informadas:**

32, 25, 29, 21, 30, 18, 27, 24, 35, 20.

**Resultado do Bubble Sort:**

18, 20, 21, 24, 25, 27, 29, 30, 32, 35.

**Resultado do Quick Sort:**

18, 20, 21, 24, 25, 27, 29, 30, 32, 35.
